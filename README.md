# CLI RENDER SLANDER
Console utility to render any image or video from your terminal.

![App Screenshot](https://snipboard.io/OpXlAV.jpg)

## Usage 
render [file-path]

#### Example:

```bash
render mogged.ppm
```

## Quick start

#### Prerequisites: You need to have cargo and ffmpeg installed

Build from source.

```bash
cargo build
```

Add the executable from the created target folder to PATH

If you dont have FFMPEG installed, install it and add it to PATH
